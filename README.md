# Trope

Trope (trope.ai) is an AI-native platform that helps ERP implementation partners deliver successful implementations faster — deploying AI agents across discovery, requirements, fit-gap analysis, data migration, approval workflows, UAT scripts, training guides, documentation, and go-live readiness, with a focus on Microsoft Dynamics 365 Business Central consultancies. Trope also maintains [Trope CUA](https://github.com/tropeai/trope-cua), an open-source (MIT) MCP-native computer-use agent for background desktop automation on Windows and macOS.

Y Combinator Summer 2026 batch, San Francisco. Backed by: y-combinator

Trope publishes no public REST API surface today; this profile captures its agent-native surfaces (MCP server, CLI, llms.txt) and security posture.
